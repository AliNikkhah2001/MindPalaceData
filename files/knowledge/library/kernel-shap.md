# KernelSHAP

> **Source**: [[pdf:SHAP.pdf#page=5|SHAP.pdf (p. 5)]]

## Definition & Core Intuition
Model-agnostic approximation of Shapley values via weighted linear regression with Shapley kernel weights.

## Mathematical Formulation
$$
\pi_x(z') = \frac{|M|-1}{\binom{|M|}{|z'|} |z'|(|M|-|z'|)}
$$

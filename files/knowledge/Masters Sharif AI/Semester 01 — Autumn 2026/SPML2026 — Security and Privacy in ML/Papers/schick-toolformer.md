# Toolformer: Language Models Can Teach Themselves to Use Tools

> Self-supervised learning of when/how to call APIs (calculator, search, …).

## Why this paper (for SPML)
Shows how tool use is learned—and why tool APIs are security-critical.

## Core ideas
- Insert API-call tokens during pretraining-style fine-tune.
- Filter by whether tool outputs help next-token loss.
- Emergent tool selection.

## How to study it
Data-generation pipeline; connect to privilege/authorization lectures.

# Duolingo French Course — Hub

Bilingual learning cluster (French + English) built from the [duolingo-french](https://github.com/etesami/duolingo-french) course by etesami. Every note below is written in **both French and English**: phrases, grammar, vocabularies, and translations are side by side.

## Pourquoi ce cluster
The Duolingo French course is structured as short lessons with interleaved French phrases, English translations, and pronunciation guides. Each unit note reproduces those bilingual tables so the graph is a self-contained textbook, not just bare connections.

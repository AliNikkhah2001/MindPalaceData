### Grammar 2

| French              | Example                 | Meaning                      |
| ------------------- | ----------------------- | ---------------------------- |
| à + l' = **à + l'** |                         |                              |
| à + la = **à + la** |                         |                              |
| à + le = **au**     |                         |                              |
| de + le = **du**    | le prix **du** sac      | The price **of the** bag     |
| de + les = **des**  | le prix **des** oranges | The price **of the** oranges |

| Newspaper boy:  Tout sur le procès d'Alexandre Jacob ! C'est le procès du siècle ! |  |  |
| Mon procès, le procès du siècle ? Mais ce n'est que le début du siècle ! La foule s'est réunie devant le tribunal. Il y a des gens qui ne m'aiment pas, je le sais. J'entends les cris et les insultes. Ces personnes-là veulent qu'on me coupe la tête à la guillotine. |  |  |
| J'entends aussi les personnes courageuses qui crient devant la police et les soldats : « Vive l'anarchie ! » J'ai des gens de mon côté. Le peuple est bon, j'en suis certain. |  |  |
| J'ai commencé à travailler à 12 ans. Ma famille avait besoin d'argent. Alors je suis devenu mousse et je suis parti en mer. Je rêvais d'aventure, et de devenir capitaine. Mais la vie de mousse était très dure. |  |  |
| À midi, on servait le déjeuner aux officiers, puis on mangeait les restes, rapidement. J'avais toujours faim, et je ne dormais presque pas. C'était crevant. |  |  |
| J'ai commencé à me demander : « Pourquoi est-ce que les gens qui ne travaillent pas ont tout, et ceux qui travaillent le plus n'ont rien ? » |  |  |
| Il faisait si froid que l'eau avait gelé dans le seau. Mes doigts aussi étaient gelés, et le vent était si fort que je risquais de tomber dans les eaux glacées. |  |  |

# La championne du fromage (Cheese Champion) - Revisited

Episode 95 · Best of (Revisited) · A2–B1 · [[index-francais]]

## Extrait (transcript, 8 lignes)
| French | English | Notes |
|---|---|---|
| Souvent, avec ma mère, j'allais acheter du fromage. Mais je ne voulais jamais entrer dans la fromagerie. Il y faisait froid. Et il y avait une mauvaise odeur. Alors, quand j'étais petite, j'ai dit : « Si je deviens vendeuse un jour, je ne serai jamais vendeuse de fromage. » |  |  |
| On est allés au musée ensemble. On parlait de politique, de religion. On regardait les œuvres d'art. On se regardait. On est restés trois heures au musée d'Orsay. Quand on est sortis, on se tenait la main. On est tombés amoureux comme ça. |  |  |
| Je lui ai dit : « Fais ce que tu veux. Mais moi, je ne viendrai jamais travailler avec toi. Je ne vendrai jamais de fromage. Jamais. Ma vie, ce n'est pas ça… » |  |  |
| J'ai pris un train et je suis allée passer la journée à Paris. On est allés au musée. Le soir, il m'a accompagnée à la gare. On s'est embrassés sur le quai de la gare. Tout s'est passé très vite. On s'est fiancés très rapidement. |  |  |
| C'est un homme avec beaucoup de passion, de charisme. Il ne voulait pas travailler pour quelqu'un d'autre. Il voulait créer sa propre entreprise. |  |  |
| À ce moment-là, j'étais étudiante. Je travaillais aussi à temps partiel pour payer mes études. Jean-François et sa mère allaient sur les marchés dans le Nord de la France avec leurs camions. Dans leurs camions, ils vendaient beaucoup de choses différentes : du pain, des fruits, des légumes… et du fromage. |  |  |
| Il m'a dit : « Dans le Nord de la France, il y a beaucoup de fermes. Et donc, il y a beaucoup de vaches et beaucoup de lait. La production de fromage est très bonne. C'est un milieu très riche et très intéressant. » |  |  |
| J'ai dit à tout le monde : « Je ne vendrai jamais de fromage. » Moi, mon rêve, c'était la vie universitaire, la littérature allemande, les livres, la poésie ! Le fromage, ce n'était pas mon but dans la vie. |  |  |

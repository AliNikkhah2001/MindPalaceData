# Les moines brasseurs (The Beer-Brewing Monks)

Episode 31 · Histoires (Stories) · A2–B1 · [[index-francais]]

## Extrait (transcript, 8 lignes)
| French | English | Notes |
|---|---|---|
| Mon colocataire et moi, on avait un bon groupe d'amis. On aimait se retrouver pour l'apéritif, et on buvait toujours de la bière. J'avais découvert cela à l'université : la bière réunit les gens. |  |  |
| À l'intérieur de moi, j'avais un dilemme. D'un côté, il y avait ce que j'étais, et de l'autre côté, il y avait ce que je voulais être. Je voulais donner plus de temps à ma religion et à la prière. C'était comme si ma vie professionnelle, ma vie personnelle et ma vie spirituelle étaient toujours en contradiction. |  |  |
| Je voulais plus de prière dans ma vie. Alors j'ai décidé de choisir une nouvelle vie et de partir vivre dans une communauté religieuse. |  |  |
| Devenir moine, c'était abandonner ma vie ordinaire. C'était laisser ma carrière et ma vie avec ma famille et mes amis derrière moi. C'était un grand changement, mais je sentais que c'était ma vocation. |  |  |
| J'avais un bon groupe d'amis. Mais maintenant, je ne savais pas ce qui allait se passer. |  |  |
| La propriété était principalement en pierre. L'église était très simple, toute blanche. C'était beau, et c'était très différent des immeubles modernes à Paris. Mais ce qui m'a le plus surpris, c'était les moines. Ils avaient tous l'air heureux, calmes. Ils avaient une vraie joie de vivre. |  |  |
| Dans cette communauté, tous les hommes se ressemblaient : ils portaient des lunettes et un vêtement noir. Je me disais : « Ils n'ont rien, et pourtant, ils sont heureux ! » Ils avaient peu de préoccupations. Ils vivaient ensemble, c'est tout. J'ai tout de suite aimé cette vie. Je savais que je voulais vivre là-bas. |  |  |
| Les moines m'ont dit de prendre mon temps, d'aller à l'université et de découvrir le monde. |  |  |

# The Secret Life of Josephine Baker - Josephine, l'icône

Episode 97 · Josephine Baker · A2–B1 · [[index-francais]]

## Extrait (transcript, 8 lignes)
| French | English | Notes |
|---|---|---|
| Mon cœur battait tellement vite. Comment est-ce-que le public allait m'accueillir ? Tout Paris était là, et je voulais leur montrer un spectacle qu'ils n'oublieraient jamais. Ce moment allait peut-être changer ma vie. |  |  |
| C'était comme si la musique avait pris le contrôle de mon corps. Et puis, je n'étais pas vraiment nue, simplement, je ne portais pas de vêtements ! Je dansais, je sautais, je riais ! Je ne voyais plus rien autour. Le public, les lumières, le stress : tout ça avait disparu. Un sentiment de liberté traversait tout mon corps. |  |  |
| À la fin du spectacle, le public était debout. Bien sûr, certaines personnes n'avaient pas aimé le spectacle, et avaient même quitté la salle, choquées. Mais la majorité des gens avaient adoré ! Quand je suis revenue sur scène, les gens ont applaudi encore plus fort. De plus en plus fort. C'était complètement fou. Pour la première fois de ma vie, j'avais la sensation d'être enfin à ma place, d'être là où je devais être. |  |  |
| Quand j'ai vu les titres des journaux, je n'en croyais pas mes yeux ! Un journal disait : « Qui est cette danseuse drôle et sensuelle qui a éclipsé toute la troupe ? ». « Tous les yeux étaient tournés sur une belle inconnue, Josephine Baker. » C'était fou ! |  |  |
| Le spectacle était un succès ! Les gens connaissaient mon nom ! J'avais l'impression d'être dans un rêve, et que j'allais finir par me réveiller. |  |  |
| C'était les deux quartiers les plus vivants de l'époque. C'est là que tous les artistes se retrouvaient : Jean Cocteau, Francis Scott Fitzgerald, Gertrude Stein. On allait danser dans les clubs de la place Pigalle ou à Montparnasse et on y faisait la fête jusqu'au matin. On était jeunes, alors on n'était jamais fatigués ! |  |  |
| « Josephine ! Josephine ! », « Un autographe, s'il vous plaît ! ». |  |  |
| Être le centre de l'attention, être admirée, parfois même adorée, c'était nouveau pour moi. Au début, c'était bizarre… Mais je m'y suis rapidement habituée ! J'ai même fini par aimer ça ! Entre les Français et moi, c'était une véritable histoire d'amour. |  |  |

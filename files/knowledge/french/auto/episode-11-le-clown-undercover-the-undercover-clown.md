# Le clown « undercover » (The Undercover Clown)

Episode 11 · Histoires (Stories) · A2–B1 · [[index-francais]]

## Extrait (transcript, 8 lignes)
| French | English | Notes |
|---|---|---|
| Il y avait une marque sur mon nez et sur mes joues. C'était la trace de mon nez rouge de clown ! On voyait aussi la trace de l'élastique du nez rouge. C'est difficile d'enlever la marque d'un élastique sur la peau. |  |  |
| Je voulais cacher la marque de l'élastique du nez rouge. J'avais peur des questions de mes collègues. |  |  |
| Je suis capable de sauter d'un monde à un autre. Je peux passer de 100 % clown à 100 % ingénieur en deux secondes. Et pour moi, la vie en double, c'est normal. |  |  |
| J'ai vite compris une chose. Les jeunes autour de moi n'aimaient pas les personnes qui faisaient plusieurs choses. Mais moi, je ne voulais pas séparer les choses. J'adorais travailler sur des problèmes scientifiques très complexes. C'était comme un grand jeu. Mais j'aimais aussi prendre des cours de théâtre. |  |  |
| Moi, je ne connaissais pas du tout le travail de clown. Mais quand j'étais plus jeune, je faisais des blagues et je me moquais souvent de moi-même. Avec ça, je faisais rire les autres autour de moi. J'aimais faire rire. Alors, j'ai voulu faire ce stage. |  |  |
| Il y avait dix élèves dans ce stage. Pendant deux semaines, on a dormi ensemble dans une grange, on a mangé ensemble. C'était une immersion totale. Pour la première fois, je vivais avec des comédiens jour et nuit. Et j'étais fier d'être comédien, moi aussi. |  |  |
| On essaie au maximum de faire comme le premier danseur. Mais on fait toujours un peu différemment des autres. Et alors, ça devient drôle. On veut encore plus imiter la personne devant nous. Et ça devient encore plus drôle ! |  |  |
| Je commence à travailler avec ma puce imaginaire. Je l'encourage pour qu'elle saute. Mais le professeur m'arrête, et me dit : « Vous n'avez pas de puces. Vous pensez que nous sommes des idiots ? » |  |  |

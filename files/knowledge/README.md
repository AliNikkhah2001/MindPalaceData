# IMPERIUM-KB

Obsidian-shareable mirror of the IMPERIUM Cognitio knowledge vault.

- Open this folder as an Obsidian vault: `[[wikilinks]]`, `#tags`, embeds work natively.
- `french/` — French learning cluster (podcast episodes, grammar, vocab, `duolingo/` course).
- `research/` — section-level notes ingested from ML/NLP/SLP/RAG PDFs.
- Generated by `tools/publish_kb.py` in the IMPERIUM repo — vault is authoritative,
  this repo is the shareable copy. Frontmatter (`title`, `title_en`, `summary`,
  `read`, `tags`, `course`) is preserved.
